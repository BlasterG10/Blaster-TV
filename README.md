# MagisTV Alpha – APK para Android

Versión de prueba 0.2. No contiene credenciales: cada usuario inicia sesión con su propio servidor.

| Archivo | Para qué equipo |
|---|---|
| `MagisTV-Alpha-lite-0.2.apk` | Ligera (Media3). Cualquier Android, Fire TV o Android TV. |
| `MagisTV-Alpha-compat-0.2-arm64.apk` | Compatible (VLC). Equipos ARM64 con canales que no abren en la Lite. |
