# MagisTV Alpha – APK para Android

Versión actual: **0.4** (sin pantalla verde en Fire TV, menos cortes, mejor calidad, inicio instantáneo).
No contiene credenciales: cada usuario inicia sesión con su propio servidor.

| Archivo | Para qué equipo |
|---|---|
| `MagisTV-Alpha-lite-0.4.apk` | Ligera (Media3). Cualquier Android, Fire TV o Android TV. |
| `MagisTV-Alpha-compat-0.4-armv7.apk` | Compatible (VLC), 32 bits. **Fire TV Stick** y la mayoría de TV boxes. |
| `MagisTV-Alpha-compat-0.4-arm64.apk` | Compatible (VLC), 64 bits. Teléfonos Android modernos. |

Los archivos con "0.2" en el nombre son la misma versión 0.4 (se mantienen para que los códigos antiguos de Downloader sigan funcionando).
